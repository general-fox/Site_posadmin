# Справочник городов и регионов

Файл `russian-locations-data.json` подготовлен на основе справочника «Города России» от DaData (HFLabs) и распространяется по лицензии CC BY-SA 4.0. [Исходный CSV](https://github.com/hflabs/city/blob/master/city.csv) · [Лицензия](https://creativecommons.org/licenses/by-sa/4.0/)

Из исходных данных взяты названия 1 117 городов и 85 регионов. Типы регионов записаны полностью. Для городов с пустым полем `city` и городов в подчинении другого города использовано собственное название из адреса или поля `settlement`. Города сгруппированы по регионам и упорядочены по алфавиту.
