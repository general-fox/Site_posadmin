# Демонстрация для заказчика — GitHub Pages

Адрес после успешной публикации: https://general-fox.github.io/Site_posadmin/

Workflow `Publish review demo` собирает и публикует демоверсию при обновлении `main` или ручном запуске в Actions. В настройках Pages выбран источник GitHub Actions.

## Что доступно

Все публичные страницы, переходы, адаптивная вёрстка, анимации, формы для проверки интерфейса и клиентский расчёт стоимости по исходному прайсу из кода.

Отправка заявок и создание PDF отключены с пояснением. Админка, API, локальная база, бот и файлы окружения не включаются в демоверсию. Цены из локальной админки в неё не переносятся. Поисковая индексация запрещена метатегами noindex; это не ограничение доступа: ссылку может открыть любой человек.

## Отдельная сборка

`node scripts/build-review-demo.mjs` копирует разрешённые исходники во временную папку, собирает статическую версию с префиксом `/Site_posadmin` и сохраняет результат в `output/github-pages`. Существующий каталог результата не перезаписывается: для повторной локальной проверки задайте новый `REVIEW_OUTPUT`, например `output/github-pages-check-2`.

Параметр `NEXT_PUBLIC_REVIEW_DEMO=true` устанавливается только внутри этой сборки. Обычные `npm run build` и `npm start` сохраняют серверные возможности для REG.RU. Не устанавливайте этот параметр на основном хостинге.

Демоверсия не зависит от включённого компьютера. Домен `posadmin.ru` и настройки REG.RU при публикации не меняются.
